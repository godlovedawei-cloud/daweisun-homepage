## Official prescribing information checked

- [DIPRIVAN](https://dailymed.nlm.nih.gov/dailymed/lookup.cfm?setid=ee0c3437-614d-4631-a061-257f5f60c70b), sections 2.2–2.6: adult induction context ranges, adult/cardiac maintenance, adult MAC initiation/maintenance and reduced dosing. **Correction to supplied file:** its statement that the current label has no separate elderly/debilitated/ASA III–IV maintenance range is inconsistent with the live label's section 2.6 dosage table, which lists 50–100 μg/kg/min. The reference includes that range. The current adult cutoff is 65, not the older 55-year cutoff.
- [Fentanyl citrate](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=1ed25b2c-334e-4021-ada1-3396f07630dc), section 2: GA adjunct categories are **total anesthetic doses**, not single additional boluses. Checked low/moderate/high totals, maintenance increments, premedication, regional adjunct, recovery-room use, and sole-anesthetic use with oxygen and a muscle relaxant. Moderate/high totals retain a brief ventilatory-support condition.
- [Rocuronium](https://dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=a54a79f7-5207-43d8-a139-7d57557caa50), sections 2.2–2.6: routine 0.6 mg/kg; 0.45 mg/kg alternative; RSI 0.6–1.2 mg/kg; obese patients' label dose uses actual body weight. The tool says **TBW**, never the ambiguous abbreviation used in some labels. Per the owner’s subsequent correction, the calculator and reference now use TBW for rocuronium, without weight selectors: routine 0.6 mg/kg and RSI rapid-onset 1.2 mg/kg. The full label RSI range is retained in the reference.
- [Etomidate](https://www.dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=4312e3c3-34de-4cb3-8abd-c24d24a4bea1&type=display), Dosage and Administration: IV induction range, usual dose, and injection time.
- [Ketamine hydrochloride](https://www.dailymed.nlm.nih.gov/dailymed/drugInfo.cfm?setid=bb912318-2e22-4469-b0a2-774803ee1bb8), section 2.2: IV and IM induction ranges and timing; alternative IV infusion regimen.
- [PRECEDEX](https://dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=9eb336de-5fa5-4b46-b40b-a7ca5a0864bd&type=display), section 2.2: adult ICU and procedural loading/maintenance, reduced loading for less-invasive procedures/age >65, awake fiberoptic maintenance, hepatic dose reduction.

## Literature and implementation distinctions

- [Ingrande & Lemmens, BJA 2010](https://pubmed.ncbi.nlm.nih.gov/21148651/) and [AAGBI/SOBA 2015](https://doi.org/10.1111/anae.13101) provide obesity-scalar context. Expert/literature weight choices are distinct from FDA instructions.
- Propofol/fentanyl automatic calculations intentionally combine the checked adult label **coefficient range** with the owner's chosen **LBW obesity-literature scalar**. The calculator explicitly identifies both; these combined calculations are not represented as FDA-labeled LBW regimens. All four adult Propofol induction contexts and all three Fentanyl total-dose categories are shown simultaneously; no context is inferred or selected.
- IBW/PBW use the same 0.91/cm formula selected in the accepted plan. Janmahasatian LBW and AdjBW coefficient 0.4 are retained. If TBW < IBW, the owner's approved convention substitutes TBW only for drug calculations requesting IBW/AdjBW; displayed IBW/AdjBW and ventilation PBW remain formula outputs. This fallback is not attributed to a universal FDA rule. Short heights receive only a short formula-check prompt, not a claim of a new validation study.
- Cefazolin/vancomycin rows remain surgical prophylaxis references from the supplied file, not treatment regimens; UFH is institutional CPB/ACT guidance, not an asserted universal obesity scalar. These rows are not tagged US label.
- Source-review notes are not included in the runtime offline payload; all actual reference content is in the cached HTML. Case data remains entirely local.
